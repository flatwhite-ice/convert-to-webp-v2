# JPG/JPEG → WebP 변환기 (convert-to-webp2)

폴더 하나만 고르면, 그 안의 **JPG/JPEG 사진을 화질 손실 없이 WebP로 한 번에 변환**해 주는 사진가용 데스크톱 프로그램입니다.
촬영 정보(EXIF), 색 프로파일(ICC), 해상도(DPI)를 **그대로 보존**합니다.

> 터미널이나 코딩 지식 없이, 창에서 버튼 몇 번이면 끝납니다.

---

## 📸 WebP가 사진가에게 좋은 이유

- **같은 화질, 더 작은 용량** — WebP는 JPEG보다 효율적인 포맷이라, 눈에 보이는 화질은 그대로면서 파일이 가벼워집니다. 포트폴리오 업로드·웹 게시·백업 용량 절감에 유리합니다.
- **무손실(Lossless) 변환** — 이 프로그램은 **무손실 모드**로만 변환합니다. 원본 사진의 픽셀이 그대로 보존되어, 화질 저하 걱정이 없습니다.
- **메타데이터 보존** — 카메라·렌즈·촬영 설정(EXIF), Adobe RGB·Display P3 같은 **색 프로파일(ICC)**, 인쇄용 DPI 정보가 변환 후에도 유지됩니다. (색 프로파일이 빠지면 색이 틀어져 보일 수 있는데, 이 프로그램은 이를 보존합니다.)

---

## ✨ 주요 기능

- **폴더 통째로 일괄 변환** — 폴더를 선택하면 그 안의 JPG/JPEG를 모두 찾아 한 번에 변환합니다.
- **무손실 변환** — 원본 화질 그대로. 품질이 떨어지지 않습니다.
- **메타데이터 유지** — EXIF · ICC 색 프로파일 · DPI 보존.
- **해상도 줄이기(선택)** — "긴 변 기준 최대 픽셀"을 정하면 비율을 유지한 채 줄여 줍니다. 원본보다 키우지는 않습니다(업스케일 없음).
- **변환 순서 선택(선택)** — 해상도를 줄일 때 "리사이즈 후 변환 / 변환 후 리사이즈"를 고를 수 있습니다. (결과 사진은 동일하며 처리 방식만 다릅니다.)
- **진행 상황 표시 & 취소** — 진행 막대와 파일별 결과(용량 변화)를 보여 주고, 도중에 취소할 수 있습니다.
- **완료 후 폴더 바로 열기** — 변환이 끝나면 결과 폴더를 바로 열지 물어봅니다.

---

## 🖱️ 사용법 (4단계)

1. **폴더 선택** — `폴더 선택` 버튼을 눌러 변환할 사진이 들어있는 폴더를 고릅니다. 발견된 JPG/JPEG 개수가 표시됩니다.
2. **(선택) 해상도 줄이기** — `긴 축 최대 해상도 지정 (px)`에 체크하고 원하는 픽셀 값을 입력합니다. 체크하지 않으면 원본 해상도를 유지합니다.
3. **변환 시작** — `변환 시작` 버튼을 누릅니다. 진행 막대와 파일별 변환 결과가 표시됩니다.
4. **완료** — "폴더를 열까요?"에서 `예`를 누르면 결과 폴더가 열립니다.

> 📂 **결과 저장 위치**: 선택한 폴더 안에 `webp` 폴더가 생기고, 그 안에 변환된 파일이 `원본이름.webp`로 저장됩니다.
> 예) `사진폴더/풍경.jpg` → `사진폴더/webp/풍경.webp`

## 💻 설치 및 실행

### 방법 A. 배포 파일로 바로 실행 (가장 쉬움 — 권장)

아래에서 사용하는 OS에 맞는 압축 파일을 내려받으세요. 별도 설치가 필요 없습니다.

| 운영체제 | 다운로드 | 용량 |
|---------|---------|------|
| 🪟 **Windows** | [convert-to-webp2-windows.zip](https://github.com/flatwhite-ice/convert-to-webp-v2/raw/main/releases/convert-to-webp2-windows.zip) | 약 57MB |
| 🍎 **macOS** | [convert-to-webp2-macos.zip](https://github.com/flatwhite-ice/convert-to-webp-v2/raw/main/releases/convert-to-webp2-macos.zip) | 약 81MB |

> 위 링크를 누르면 곧바로 다운로드가 시작됩니다.
> 저장소에서 직접 받으려면 [`releases/` 폴더](https://github.com/flatwhite-ice/convert-to-webp-v2/tree/main/releases)를 확인하세요.

다운로드한 압축 파일로 실행하는 방법은 아래 OS별 안내를 따르세요.

#### 🪟 Windows
1. `convert-to-webp2-windows.zip`의 압축을 풉니다.
2. 생긴 `convert-to-webp2-windows` 폴더를 엽니다.
3. **`convert-to-webp2.exe`** 를 더블클릭합니다.
4. "Windows의 PC 보호" 안내 창이 뜨면 → **추가 정보** → **실행** 을 누릅니다.
   *(이 프로그램은 코드 서명이 되어 있지 않아 나타나는 정상적인 안내입니다.)*

> ⚠️ `convert-to-webp2.exe`와 `_internal` 폴더는 **항상 같이 있어야** 합니다. exe만 따로 옮기지 마세요. 폴더째로 옮겨 주세요.

#### 🍎 macOS
1. `convert-to-webp2-macos.zip`의 압축을 풉니다.
2. 생긴 `convert-to-webp2-macos` 폴더에서 **`convert-to-webp2`** 실행 파일을 엽니다.
3. "확인되지 않은 개발자" 경고가 뜨면 → 실행 파일에서 **마우스 우클릭(또는 Control+클릭) → 열기 → 열기** 를 선택합니다.
   *(또는 `시스템 설정 → 개인정보 보호 및 보안`에서 실행을 허용합니다.)*

> ⚠️ `convert-to-webp2` 실행 파일과 `_internal` 폴더는 **항상 같이 있어야** 합니다. 실행 파일만 따로 옮기지 마세요. 폴더째로 옮겨 주세요.

#### 🐧 Linux
Linux용 사전 빌드본은 제공되지 않습니다. 아래 **방법 B(소스에서 직접 빌드)** 로 만들어 사용하세요. 빌드 후 `dist/convert-to-webp2-linux/` 폴더의 **`convert-to-webp2`** 실행 파일을 실행하면 됩니다. (터미널: `./convert-to-webp2`)

---

### 방법 B. 소스에서 직접 빌드 (Python 필요)

직접 실행 파일을 만들고 싶을 때 사용합니다. **Python 3.10 이상**이 필요합니다.

#### 🪟 Windows
- `build.bat` 파일을 **더블클릭**합니다. (또는 PowerShell에서 `./build.ps1`)
- 자동으로 필요한 라이브러리를 설치하고 실행 파일을 만듭니다.

#### 🍎 macOS / 🐧 Linux
터미널에서 프로젝트 폴더로 이동한 뒤:
```bash
./build.sh
```
- 특정 파이썬 버전을 지정하려면: `PYTHON=python3.12 ./build.sh`

#### 빌드 결과물
- 실행 폴더: `dist/convert-to-webp2-<OS>/`
- 배포용 압축본: `dist/convert-to-webp2-<OS>.zip`

> 💡 **macOS에서 빌드가 안 될 때**: 일부 Homebrew 파이썬은 최신 macOS와의 호환 문제로 설치 단계에서 멈출 수 있습니다. 이 경우 [python.org 공식 설치본](https://www.python.org/downloads/)으로 Python 3.10+ 를 설치한 뒤 다시 시도해 보세요. (자세한 안내는 `build.sh` 실행 시 화면에 표시됩니다.)

## ❓ 자주 묻는 질문

**원본 사진이 지워지나요?**
아니요. 원본은 그대로 두고, 변환본만 `webp` 폴더에 새로 만듭니다.

**어떤 파일이 변환되나요?**
선택한 폴더 **맨 위에 있는** `.jpg` / `.jpeg` 파일만 변환합니다. (대소문자 구분 없음) **하위 폴더는 포함되지 않습니다.**

**같은 이름의 결과 파일이 이미 있으면요?**
덮어씁니다.

**"리사이즈 후 변환"과 "변환 후 리사이즈"는 뭐가 다른가요?**
WebP가 무손실이라 **최종 사진은 동일**합니다. 내부 처리 순서와 속도만 다릅니다. 잘 모르겠다면 기본값(리사이즈 후 변환)을 쓰면 됩니다.

**흑백(그레이스케일)이나 CMYK JPEG도 되나요?**
됩니다. WebP는 CMYK를 지원하지 않으므로 자동으로 RGB로 변환되어 저장됩니다.

**변환 중에 닫아도 되나요?**
변환 중 창을 닫으면 종료 여부를 다시 물어봅니다. 진행 중이던 파일은 안전하게 마무리됩니다.

## ℹ️ 참고 / 현재 범위

- **입력 포맷**: JPG/JPEG만 지원 (PNG·TIFF 등은 미지원)
- **탐색 범위**: 선택한 폴더의 최상위만 (하위 폴더 제외)
- **압축 방식**: 무손실 고정 (손실 압축 품질 조절 없음)
- **미리보기/썸네일**: 제공하지 않음
